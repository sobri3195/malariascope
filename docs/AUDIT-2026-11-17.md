## Commands and source review

Use Node 22+ and `pdftotext` (Poppler). From the repository root:

```sh
npm ci
# Discover the latest uniquely indexed PDF for the selected year, without writing:
npm run data:sync:malaria -- --year 2026 --dry-run
# Select an exact edition:
npm run data:sync:malaria -- --year 2026 --bulletin 45 --dry-run
# After reviewing the result, omit --dry-run to publish local version assets.
```

The automatic path downloads HTTPS links from the official publication index and reads PDF text directly. It supports only an explicit seven-column text table and recognizable source metadata. It rejects unknown layouts and dates, rather than guessing numeric column positions. The actual M44/M45 layout still needs verification with accessible official PDFs; automatic extraction is not yet proven against those editions.

For an inaccessible source or an unsupported table layout, obtain the official PDF using authorized access, then use a reviewed seven-column CSV and metadata file:

```sh
npm run data:sync:malaria -- --year 2026 --bulletin 45 \
  --pdf /path/to/official-m45.pdf --csv /path/to/official-attachment.csv \
  --metadata /path/to/reviewed-m45-metadata.json --dry-run
```

Metadata keys: `year`, `bulletin` (number), `weekThrough`, `publishedAt` (ISO date), `dataAsOf` (ISO timestamp with timezone), `sourceUrl` (official HTTPS PDF URL), `national` (printed national integer), `nationalPage`, `provincePage`, `provinceColumn` and `confirmedColumn` (exact CSV headers). `retrievedAt` is recorded by the runner at execution, separately from publication/data times. The seven headers are preserved; column names for province and confirmed cases must be explicitly mapped. Indonesian thousands separators are accepted, missing values and decimal/ambiguous numbers are rejected. The converter also retains the previous internal Markdown CSV contract via `--skdr-markdown`.

Both paths validate the full 38-province set, full-label master mapping, source pages, printed values, source metadata and audit acceptance gates before publication. Papua and each newly formed Papua province have distinct full-label matches. Unknown/ambiguous rows stop the run. A reviewed CSV does not bypass PDF comparison. If source metadata appears only in the index, or national prose/table formatting is unsupported, the current verifier stops; this remaining layout work needs the actual PDF/index evidence.

## Publication, retention and recovery

`skdr/sources/<pdf-sha256>.pdf` retains source bytes. `skdr/versions/<edition>-<version>.json` holds the immutable snapshot. Version identity includes source hash and data/metadata but excludes retrieval time, so repeated checks distinguish `unchanged`, `published` (new edition) and `revised` (same edition). The catalog points at a version only after its assets have been written. A failed check leaves catalog/source observations unchanged; `sync-manifest.json` records the attempt separately. `--dry-run` writes no artifacts. `--output /tmp/isolated-directory` permits isolated publication testing.

The selector reads `skdr/catalog.json`; absent an explicit snapshot, it selects the latest complete catalog entry. Explicit `snapshot=2026-m44` still selects that edition. With no complete entry, the bundled partial M44 remains visibly incomplete. Reconciliation and provenance travel with exports at national, province and empty-district selections. An unavailable district remains empty with a separate province context card.

To roll back, review the retained immutable version and restore the catalog entry's `path` and `version` together (and `latest` if necessary) through a reviewed commit. Never overwrite an old version file or rewrite its PDF hash. Run the same validation/build/browser checks after rollback.

SISMAL refresh is now explicit and independent: `npm run data:sync:malaria -- --year 2026 --sismal-only`. Existing annual retention protections remain in place.
