# Methodology & Evidence workspace

`/methodology` presents a concise **Data Coverage & Research Summary** dashboard, source availability timeline, district coverage bars, transparent quality indicators and searchable evidence catalog. The global year, district and dataset determine selected observations, case totals and field completeness; the risk mode and model remain synchronized with the shared context. The source archive period is explicitly distinguished from the selected year. Empty contexts produce no imputed values.

The coverage denominator is explicit: 49 actually bundled unique outcomes out of 54 potential district-years, separate from study metadata reporting 53/54 and the complete 48-row eight-district forecasting panel. Case-field completeness is a separate selected-source indicator and is never labeled total study completeness. Duplicates and four unresolved source issues remain visible. Package checksum checks are not independent auditing of the source reports or operational validation.

The evidence catalog supports text search, category, verification status and global-context/full-archive filters, provenance links, matching-source JSON/CSV exports and browser print/PDF. Row-level sources are filtered by actual year/district. Study-wide summaries are labeled separately rather than assigning them district observations. Exported context includes year, district, risk mode, model and active dataset. Synthetic records are excluded.

Full methodology, forecasting splits, ablation, uncertainty, quantitative findings, quality treatments, provenance, checksum metadata and raw objects are lazy-loaded behind **Advanced Technical Details**. Raw JSON requires a further deliberate disclosure. Existing scientific results and limitations are preserved; the main view states the retrospective limitations prominently. The former technical tabs remain accessible inside that disclosure. Public research artifact files/checksums are unchanged.

## 100,000 synthetic demonstration records

`public/data/demo/synthetic-100000.csv` contains exactly 100,000 artificial records, each explicitly classified `SYNTHETIC_NOT_OBSERVED`, across nine fictional districts and six artificial year labels. These are record-level demo examples, not district-year surveillance observations. Repeated fictional district/year labels are intentional. There are no real geometry matches, observed malaria outcomes, climate measurements, model results or scientific validation claims in this fixture.

Reproduce deterministically from the repository root with `node scripts/generate-synthetic-demo.mjs`. The separate `metadata.json` records the fixed seed, exact row count, SHA-256, source and limitations. No additional package is required.

The **Synthetic Demo — 100,000 Records** disclosure loads the fixture only on explicit request, verifies its hash/count/classification and parses it in a background worker. Search, fictional-district/year filtering and 50-row pagination keep the preview bounded. Download and unload controls are provided. Demo data are held in component memory only: no verified manifests, global dataset selection, imported-surveillance storage, analytical alerts, risk calculations or research reports are modified. The demo is not automatically cached by the mobile service worker. Browser print excludes the synthetic preview.

Validation: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, production-preview `tests/coverage-summary.mjs`, `tests/methodology-evidence.mjs` and existing research/desktop/IoT acceptance. Coverage acceptance checks global synchronization, actual totals, empty search, source export, exact 100,000-row loading, pagination/filtering, demo failure states, immutable research storage and mobile/print behavior. Unit checks verify actual completeness, missing/duplicate treatment and the synthetic fixture's hash/count/isolation.
