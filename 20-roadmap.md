# Roadmap

The items below are proposals for future scope, not implemented capabilities, release promises or scientific claims.

## Maintain the current research workspace

Keep analytical source isolation, transparent methodology, provenance, mobile accessibility and browser regressions reliable. Address demonstrated defects before expanding the system. Preserve the distinction between build health and scientific validation.

## Evidence and model reproducibility

Obtain authorized source records and licenses, improve denominator/period coverage, and expose unresolved data gaps. A reproducible training pipeline would need declared features, model artifacts, versioned splits and independently reviewable evaluation. Prospective claims require actual later outcomes and an approved evaluation protocol.

## Optional multi-user services

If requested, design authenticated roles, secure storage, server audit trails and retention controls. Define migration and API contracts before implementation. Browser-local profiles and this agent handbook do not supply those capabilities.

## Environmental integration

Connect legitimate authorized sensors or public feeds with calibration, freshness, quality and geographic-match evidence. Synthetic environmental values and adapter configuration alone cannot establish a live network.

## Governance and accessibility

Clarify application/data licensing with the owner and pursue independent accessibility and scientific review where appropriate. Define acceptance evidence for each proposed item using [planning](04-planner-agent.md) and [testing](18-testing-standard.md). No roadmap item authorizes operational recommendations or automatic clinical decisions.

## Implemented foundations

See [Research completion](docs/RESEARCH-COMPLETION.md) for the executable training/backtest pipeline, portable artifacts, optional authenticated services, draft recovery, full backups and research review workflows. Source reconciliation, original licensed records, independent verification, live sensors and production service deployment still depend on external evidence/configuration. Smartwatch remains a browser demonstration by user choice.
