# Repository structure

| Path                                                    | Responsibility                                                     |
| ------------------------------------------------------- | ------------------------------------------------------------------ |
| `src/main.tsx`                                          | Entry point, shared Provider and lazy shell selection              |
| `src/DesktopApp.tsx`                                    | Main workspace routes and shared UI                                |
| `src/store.tsx`                                         | Dataset registry, selections, projection and local persistence     |
| `src/analytics.ts`, `src/*-engine.ts`                   | Pure calculations, validation and analytical rules                 |
| `src/research-data/`                                    | Checksummed study loader, selectors and evidence panels            |
| `src/Map.tsx`, `src/MapCanvas.tsx`, `src/geometry.ts`   | GIS workspace, map lifecycle and geometry validation               |
| `src/*worker.ts`                                        | Background spatial, hotspot and synthetic-preview work             |
| `src/mobile/`, `src/desktop/`, `src/iot/`, `src/watch/` | Dedicated interface shells and their helpers/styles                |
| `src/*.test.ts`                                         | Node unit tests for analytical contracts                           |
| `public/data/verified/`                                 | Supplied study extraction, metadata and public district geometries |
| `public/data/demo/`                                     | Explicitly synthetic fixtures and metadata                         |
| `public/mobile-sw.js`                                   | Mobile offline asset cache                                         |
| `scripts/`                                              | Reproducible synthetic-fixture generators                          |
| `tests/`                                                | Browser acceptance scripts                                         |
| `docs/`                                                 | Feature-specific research and implementation notes                 |
| `.github/workflows/ci.yml`                              | Build and browser validation pipeline                              |
| `vercel.json`                                           | Static-host route and cache configuration                          |
| `00-project-rules.md` through `20-roadmap.md`           | Project and role handbook                                          |

`dist/` is generated by the build and is not a source directory. Follow existing file boundaries rather than adding empty backend/agent-service folders for roles that have no runtime implementation.
